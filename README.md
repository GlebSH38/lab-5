 Часть 1: Tkinter (part1_tkinter.py)
В данном файле реализовано главное окно с кнопками для вызова окон каждого задания:
1. Средняя сложность 1 (Окно с кнопкой «Привет»): При нажатии на кнопку выводится приветствие.
2. Средняя сложность 6 (Прогрессбар): Анимация заполнения прогрессбара от 0 до 100% по нажатию на кнопку (с использованием time.sleep и update).
3. Средняя сложность 9 (Цветная панель): Панель (Frame), которая меняет свой цвет на случайный из заданного списка при нажатии на кнопку.
4. Повышенная сложность 2 (Рисование фигур мышью): Холст (Canvas), на котором можно рисовать овалы, прямоугольники и линии с помощью зажатой левой кнопки мыши. Реализован выбор фигуры через Radiobutton.

Часть 2: PyQt5 (part2_pyqt.py)
5. Повышенная сложность 9 (Приложение PyQt с таблицей): Приложение с таблицей (QTableWidget), предзаполненной тестовыми данными. Реализована кнопка «Добавить строку», которая добавляет пустую строку в конец таблицы.
